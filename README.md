# Minesweeper Roguelite

Godot 4 的扫雷肉鸽项目基础工程，首发平台为 Web。

## 打开与运行

1. 使用 Godot 4.3 或更高版本导入 `project.godot`。
2. 运行主场景验证自适应 UI 壳。
3. 在 Project → Export 选择 **Web** 预设，导出至 `build/web/index.html`。

## 当前玩法

- **开场**：每份存档第一次点「开始游戏」会先放耳机提示（五行字逐行砸下来，任意键或点击跳过）与开场剧情（四页插画配鸟叫台词，长按跳过），放完记进存档，之后不再重复；清空存档会再放一次。
- **陈列柜选关**：标题页点「开始」进入陈列柜，七件关卡展品排成一列摆在波点桌布上，一次只看一件，左右箭头（或 ←/→）切换（打通上一关才开下一关，未解锁的是灰泥胚）；切过来的展品像搭积木一样重新搭起来，再点「进入关卡」。第 1 关的展品上有一只蚊子飞来飞去：鼠标慢慢靠近它会躲，快速挥过去才能拍死；拍满 3 只拿成就【三振出局】，之后这一轮里它就不再出现了。第 2 关的岛面上时不时晃出一只动物（狗熊 / 猴子 / 企鹅 / 狐狸）在田里溜达，鼠标停到它身上乌鸦就俯冲下来薅走一撮毛——薅够 3 种拿成就【薅遍四野】。第 1 关含教程：第 1 盘是**强引导**（5×4 固定雷位，遮罩挖洞 + 小手指 + 引导文本，六步逐个放行点击：翻格 → 认数字 → 踩雷掉血 → 看血条 → 右键标雷 → 点数字推理通关），第 2 盘是**伙伴牌课**（左键任意格找出夜鹭牌 → 鸟起飞前圈住牌讲「翻出即自动生效」、按「看它表演」→ 演出完弹出**伙伴图鉴**：8 位伙伴上图下文的作用说明），之后的教学盘自由练习；第 2～6 关按盘列表推进。第 7 关「无尽远海」是**无尽模式**：没有盘列表也没有目标盘数，每盘从全部形状族里随机抽形状（同一局内可复现），盘面每 3 盘放大一号（7 → 10 封顶）、雷密度每盘上涨直到封顶，只有血量归零才收场；倒下时弹「止步第 N 盘」结算上榜，柜子上记「最远第几盘」。无尽关的商店是**鸟窝**（槽位制）：一格住一只伙伴，每盘按窝里的鸟埋牌；起手 6 格、四只起手鸟已入住，窝满了再买就得点一格说换掉谁（按下不扣钱，点格子才结账），花钱还能扩建三次、每次 +3 格、最多 15 格；商店里按鸟归类显示「总数 X / Y ｜ 夜鹭×3 红隼×2……」。对战仍为正方形盘面。一盘里伙伴牌连锁触发太多、雷却已经被提前清光时，会自动展开一张金色的**奖励盘**（同尺寸、只有雷、不再发新牌）：剩下的伙伴在它上面把效果放完，标出的雷照常算钱算分，这一段不会掉血，放完照常进下一盘。
- 10 × 8 棋盘，共 12 枚地雷。
- 左键翻开地格，右键插旗或撤旗。
- 首次翻开的地格及其周围八格不会布雷。
- 空白地格会自动连锁展开；翻开全部安全地格即获胜。
- 每局包含 3 盏灯和 3 个罗盘：灯揭示周围 3 × 3 区域并自动标雷，罗盘随机寻找一个尚未揭开的安全格。
- 同一次翻格发现多个道具时，道具按照格子顺序逐一结算；道具造成的新发现会继续加入结算队列。
- 地格采用泥坑底、内侧阴影、内容、接触阴影、前景泥块和草皮盖板的分层结构；翻格包含草皮掀飞、内容弹出、碎草、泥块与扬尘效果。
- 鼠标光标是自定义圆点，附带暖金拖尾和点击涟漪（左键金色、右键青色）；特效全部程序化绘制，鼠标停下后自动休眠。
- 失败或胜利后可通过“重新布置雷区”开始新局。
- **鸟类图鉴**：标题页点「鸟类图鉴」翻开队伍名册。每只鸟一张卡：头像播的就是它在栖枝上那套待机帧（相位错开，八只不会一起抬头）、名字、外号和一句能力说明。还没加入的只露一个黑剪影，名字打码成「？ ？ ？」，能力那行换成解锁条件（「打完教学第 N 关加入」），右上角记着「已收录 N/8」——图鉴因此也是一张「还差谁」的清单。
- **自定义模式**：标题页点「自定义」进编辑器。左键拖矩形画可玩格、右键擦，配雷数与 9 种道具数量后开局；打完可原配置重开、返回编辑再改、或回标题。配置可导出为 JSON（导出时询问关卡名，即文件名；地图是逐行 0/1 数组），编辑器里也能导入 JSON。自定义局不写存档、不进商店。

棋盘规则位于 `scripts/game/minesweeper_board.gd`，显示与交互分别位于 `scripts/main.gd` 和 `scripts/ui/mine_cell.gd`。
自定义模式的数据与 JSON 进出在 `scripts/game/custom_level.gd`，编辑器在 `scripts/ui/custom_level_editor.gd`。
鸟类图鉴的总表在 `scripts/game/bird_catalog.gd`（名字、外号、能力、解锁条件、待机帧），页面在 `scripts/ui/bird_codex_screen.gd`（整页由代码搭建，两行铺满、列数按鸟数算）；解锁状态仍由 `main.gd` 的那一排 `*_unlocked` 说了算，`_apply_bird_unlock_visibility()` 每次跑都会推给图鉴。校对图用 `tools/capture_bird_codex.gd`。
选关界面是「陈列柜」（`scenes/stage_cabinet.tscn`）：七关（含第 7 关无尽）各是一件独立的低模展品排成一列摆在同一张波点桌布上，一次只看一件，左右箭头切到相邻关卡时它会重新搭起来；前六关各有专属主景、主题与配色（青草坡果园小屋 / 麦垄风车谷仓 / 老井村石梯田古树井亭 / 双桥潭心亭与双拱桥 / 深潭瀑布吊脚屋 / 尽头港防波堤灯塔船库），桌布波点跟着当前关卡换色；展品是活的（树摇、鸟点头、船晃、风车水车转、炊烟、鸽群绕圈飞、云飘过投下云影），没通关的关是一副荒废相（枯树、封板窗、缺瓦、干井、沉船、熄灯、鸟都走了），通关后先看排行榜结算，回到柜子它会当场复原（一圈光、满岛飘起的叶片花瓣与光点、「复苏」标题和几句关卡短句）再带你去下一关；每关模型由 `tools/build_diorama_<id>.py` 用 Blender 无头生成到 `assets/dioramas/<id>/`，第 7 关无尽暂为灰泥胚占位。世界地图位于 `scripts/ui/world_map.gd` 与 `scenes/world_map.tscn`（六边布局是可在编辑器里手改的数据，初稿由 `tools/build_world_map.gd` 生成一次；运行时按方格重铺体素地块，图集配色由 `tools/build_clean_atlas.py`、方块树由 `tools/build_clean_trees.py`（Blender 无头）生成），关卡数据在 `scripts/game/stage_table.gd`，盘面形状库在 `scripts/game/board_shape.gd`。
